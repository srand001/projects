API
---

This allows API calls to GET data from a MySQL database containing a customer list on this server using PHP.

API calls supported are below:

GET         : Get all data
Get <id>    : Get data for just one item with 'id' value
POST        : Creates a new data entry
PUT <id>    : Updates data for just one item with 'id' value
DELETE <id> : Deletes entry for just one item with 'id' value


Note: Use' POSTMAN' software for testing this api.
