API Tests

This allows API calls to retrieve data from a MySQL database on this server. Uses PHP V8 as the backend processing language.

Supported API calls are shown below:

  • GET : Get all data
  • Get [id] : Get data for just one item with 'id' value
  • POST : Creates a new data entry
  • PUT [id] : Updates data for just one item with 'id' value
  • DELETE [id] : Deletes entry for just one item with 'id' value

Examples:

Test: GET

http://www.randsoft.co.uk/api/read.php


Test: POST

http://www.randsoft.co.uk/api/create.php

JSON body data: { "fname": "Robert", "lname": "Jones", "phone": "12345678", "email": "robert@hotmail.com" }


Note: It is recommended to use 'POSTMAN' software or similar for testing this API.
